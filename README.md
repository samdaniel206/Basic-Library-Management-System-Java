# Basic Library Management System in Java

This is **Task 5** of the **Tech-Driven Internship Program by Kodbud**.  
This Java console application implements a **basic Library Management System** that lets users add new books, display all books, search by title, and remove books.

## 📚 Features
- Add new books (title, author, ISBN)  
- Display all books available in the library  
- Search for a book by title (partial match supported)  
- Remove a book by title  
- Simple menu-driven console interface

## ▶️ How to Run
1. Save the file as `LibraryManagementSystem.java`
2. Open terminal inside the project folder and run:
    javac LibraryManagementSystem.java
    java LibraryManagementSystem
   
## 💡 Concepts Used
- `ArrayList` to store book objects  
- Custom `Book` class (title, author, ISBN)  
- Basic CRUD operations (Create, Read, Delete)  
- Loops, conditionals, and Scanner for user input
